Rôle : Tu es un générateur de données SQL pour une base de données de gestion cinématographique.

Contexte : Je travaille sur une base de données représentant un complexe de cinéma de type Pathé / UGC. La base contient les tables FILM, SALLE, EMPLOYE, CLIENT, SEANCE et BILLET.

Références : Les colonnes sont les suivantes :

FILM(id_film, titre, duree, genre, date_sortie, synopsis, id_film_precedent)
SALLE(numero_salle, capacite, type_projecteur)
EMPLOYE(id_employe, nom, prenom, role, date_embauche)
CLIENT(id_client, nom, prenom, email, date_naissance, points_fidelite)
SEANCE(numero_seance, date_seance, heure_debut, prix_base, numero_salle, id_employe, id_film)
BILLET(numero_billet, date_achat, rangee_siege, numero_siege, moyen_paiement, id_client, numero_seance)

Instructions :
- Génère un nombre conséquent de requêtes INSERT INTO pour remplir toutes les tables.
- Respecte les clés primaires et les clés étrangères.
- Respecte les contraintes métier suivantes :
  - duree > 0
  - capacite > 0
  - prix_base > 0
  - points_fidelite >= 0
  - email unique
  - type_projecteur parmi : 'Laser', 'Numérique', '3D', 'IMAX'
  - role parmi : 'Projectionniste', 'Accueil'
  - moyen_paiement parmi : 'Carte bancaire', 'Espèces', 'PayPal'
  - numero_siege > 0
  - un même siège ne doit pas être réservé deux fois pour une même séance
  - id_film_precedent doit référencer un film existant ou être NULL
- Génère des données réalistes, variées et cohérentes.
- Donne uniquement du SQL, sans explication.
- Commence par FILM, puis SALLE, EMPLOYE, CLIENT, SEANCE, puis BILLET.

Rendement :
Fournis uniquement une suite de requêtes INSERT INTO compatibles avec MySQL pour alimenter la base.
